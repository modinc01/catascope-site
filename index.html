相場が見えない理由

Catawiki には、終了済みの検索がありません。

出品中の価格は見えても、実際にいくらで落ちたか、どんな状態の品がいくらだったかは、ロットを1件ずつ開かないと分かりません。

相場

落札価格が分からない

公式サイトの検索は出品中のみ。終了したロットは1件ずつURLを掘らないと見えません。

状態

同じ型番でも、状態で値段が違う

Fair と Good では落札価が数万円変わることも。平均値だけ見ても、自分の手元の品の相場は分かりません。

手取り

手数料と為替で、手元に残る額が読めない

落札価から出品者手数料を引き、ユーロを円に直す。会場でその計算をしている時間はありません。

使い方

仕入れ先のページから、ボタン1つ。

商品ページを開く

エコオク、ヤフオク、メルカリの商品ページを開きます。CataScope が商品名と画像を自動で読み取ります。

「落札相場を見る」を押す

画面右下に出るボタンを押すだけ。日本語の商品名は自動で英訳し、型番も抽出します。

落札相場を見る

30秒で落札履歴

Catawiki の直近の落札を集め、状態・落札価・手取り換算・見積・終了日を1画面に並べます。

商品名・型番を打ち込んでの検索、画像や画像の一部（範囲選択）からの検索にも対応しています。

結果画面の見どころ

一覧を出すだけでは終わらない。

コンディション別
Catawiki が各ロットに付けた状態（New / Good / Fair など）をそのまま表示。ワンクリックでその状態だけに絞り込め、中央値も連動して再計算されます。
価格帯バー
最安から最高までの帯に、落札1件ずつを点で打ちます。金の印が中央値。外れ値がひと目で分かります。
手取り換算
各落札価から出品者手数料（初期値 12.5%）を引き、ECB の為替で円にした額を併記します。
見積との比較
Catawiki の専門家見積と実際の落札価を並べて表示。見積が当てになる品目かどうかが分かります。
売れた / 売れ残り
リザーブに届かず終了したロットも色分けして残します。何件中何件が売れたかが数字で出ます。

よくある質問

導入前に、よく聞かれること。

落札データはどこから取っていますか

Catawiki の公開されている終了済みロットページから、あなたのブラウザが直接読み取ります。CataScope のサーバーに落札データを蓄積することはありません。

すべての落札が見えますか

いいえ。直近の主要な落札（最大20件）を集めます。ニッチな品目では件数が少ないことがあります。

表示された相場で売れますか

相場は直近の落札からの目安です。中古品は状態・付属品・時期で価格が大きく変わるため、落札価格や売れ行きを保証するものではありません。最終的な入札判断はご自身で行ってください。

Catawiki の公式ツールですか

いいえ。CataScope は Catawiki B.V. とは無関係のサードパーティツールです。

対応ブラウザとインストール方法は

Chrome と、Chrome 拡張が使える Edge で動作します。Safari と Firefox には対応していません。申し込み後にメールでお送りする手順に沿って、拡張ファイルを Chrome に読み込み、ライセンスキーを設定画面に貼り付けるだけです（約 2 分）。

解約はどうすれば

設定画面の「契約を管理」からいつでも解約できます。解約後は次回更新日まで利用でき、日割り返金はありません。
